# Trenches Kombat: pose prompts (copy and send)

Every prompt below is complete. Nothing to fill in.

## How to do it

1. Open a free image tool (Gemini, ChatGPT, Microsoft Designer / Bing Image Creator, Meta AI or Grok).
2. **Upload the fighter's card.**
3. Copy **Prompt 1**, paste it, send. Download the image.
4. In the same chat, do the same with **Prompt 2**, **3** and **4** (upload the card again if the tool asks).
5. Name the downloads `<fighter-id>-sheet1.png` … `<fighter-id>-sheet4.png` (for example `king-sol-sheet1.png`)
   and send them to me. I cut out every pose and wire it in.

That's **4 images per fighter**, 20 poses in total.

**Two options:**
- **Quick option:** the 4 universal prompts right below work for *every* fighter, because the uploaded card shows who it is.
- **More accurate option:** scroll to your fighter's section further down. Same 4 prompts, but with the character
  described in words too, which helps the tool keep the outfit right.

If one image comes out wrong (facing left, feet cut off, wrong outfit), reply in the same chat:
*"Redo that. Same character, all poses facing right, full body with feet visible, plain white background."*

# Universal prompts (any fighter)

### Prompt 1 (idle, walk, crouch, jump, block, hit)

```
Using the uploaded card as the character reference, make a 2D fighting game sprite sheet of the SAME character shown on the uploaded card.

A 3 x 2 grid of 6 separate full-body poses, all facing RIGHT (side view), all the same size, evenly spaced, not touching or overlapping. In this order, left to right, top to bottom:
1. standing fighting stance, body turned sideways, knees slightly bent, feet shoulder-width apart, both fists raised in guard near the chin
2. walking forward in fighting stance, front foot stepping forward, fists up in guard
3. crouching low in guard, knees deeply bent, fists up protecting the face
4. jumping in the air, knees tucked up towards the chest, fists up, feet off the ground
5. blocking: both forearms raised in front of the face and chest, body leaning back slightly, knees bent
6. getting hit in the face: head snapped back, body bending backwards, arms flung out, one foot lifting

Rules:
- Exact same face, hair, outfit, colours and accessories as the card in every pose. Same anime cel-shaded style.
- Full body head to toe in every pose, nothing cropped.
- Realistic human proportions and balance, like Mortal Kombat / Street Fighter sprites.
- Plain solid flat white background (#FFFFFF) everywhere. No frames, no grid lines, no text, no labels, no numbers, no shadows, no effects.
- Landscape image, 3:2 ratio.
```
